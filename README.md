## Objectif:

Ce projet a pour objectif de fournir une calcultrice simple avec une interface pour l'utiliser

## Prérequis d'installation

- Avoir Python d'installer
- Avoir pip de Python d'installer 
- Installer les dépendances avec `pip install -r requirements.txt`

## Instructions d'installation

1) Créer un environnement virtuel avant d'installer les dépendances (le faire a la racine du projet)
   1) `python -m venv .venv`
   2) Sur windows: `.\.venv\Scripts\Activate.ps1`, Sur macOS ou linux: `source .venv/bin/activate`

2) Installer les dépendances du projet:
   `pip install -r requirements.txt`

## Lancer le projet
1) Ouvrir un terminal à la racine du projet
2) Activer l'environnement virtuel: `.\.venv\Scripts\Activate.ps1`
3) Lancer l'application: `python -m server.app`
4) Ouvrir l'adresse dans le navigateur
